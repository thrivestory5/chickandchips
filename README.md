## 🌟 Features

- **Cinematic Awwwards-Tier Visuals & Motion**: Smooth scrolling with Lenis, 3D perspective transforms, and kinetic marquee tickers.
- **Synthesized Web Audio Sound Effects**: Interactive crispy bite/crunch SFX, pop clicks, and success chimes with persistent audio mute toggle.
- **Interactive "Build Your Happy Tray" Simulator**: Customizer enabling customers to build meal trays (Main + Carbs + Dipping Sauce + Drink) with live price tally and one-click WhatsApp order export.
- **Interactive 2x2 Strategic Positioning Matrix**: Dynamic scatter chart mapping the market "Sweet Spot" over global fast-food chains and local street food.
- **Store Tour & 80-Seat Isometric Floorplan**: Interactive blueprint with clickable hotspots (POS Kiosks, Standardized SOP Kitchen ≤5 Min, 80-Seat Dining Area, Delivery Bay).
- **Interactive Franchise ROI Calculator**: Financial model with real-time sliders for daily customer volume and average spend (Rp 310.4M/mo omset, 60% gross margin, 37.5% ROI).
- **Grand Opening Hub & 20% Voucher Claim**: Live countdown timer for the 20K opening deal and interactive voucher generator with confetti celebrations.
- **Delivery & Multi-Channel Integration**: Direct modals for GoFood, GrabFood, ShopeeFood, and WhatsApp customer service.

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/thrivestory5/chickandchips.git

# Navigate to project directory
cd chickandchips

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🌐 Deploy to Vercel (Automatic CI/CD)

This repository is configured for automatic deployment on **Vercel** (`chicknchips.vercel.app`):
1. Import repository `chickandchips` into [Vercel Dashboard](https://vercel.com/new).
2. Framework Preset: **Vite**.
3. Build Command: `npm run build`.
4. Output Directory: `dist`.
5. Set Project Name to `chicknchips` (or assign custom domain `chicknchips.vercel.app` under **Project Settings > Domains**).
6. Every `git push` to `main` will automatically trigger a production build and deployment.
